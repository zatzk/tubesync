### 🏛️ Principais Decisões Arquiteturais Consolidadas (ADRs)

1. **Derivação de Chave Criptográfica ([`ADR-01`](file:///home/ozymandias/code-documentation/personal/tubesync/rfcs/rfc-tubesync-core-architecture.md#adr-01-cifragem-aes-256-gcm-transparente-via-seed-de-instalação--salt-local)):**
   - **Decisão:** Modelo transparente sem fricção de UX via **AES-256-GCM** (Web Crypto API). A chave é derivada por PBKDF2 (SHA-256) combinando o identificador da extensão (`browser.runtime.id`), um seed de entropia de 256 bits gerado na instalação e gravado no storage local, e um salt único de 128 bits por operação.
   - **Justificativa:** Elimina credenciais em texto claro no [`storage.ts`](file:///home/ozymandias/Code/tubesync/src/services/storage.ts) sem forçar o usuário a digitar uma senha mestra a cada interação ou despertar do Service Worker.
2. **Setup e Fatiamento de Testes ([`ADR-05`](file:///home/ozymandias/code-documentation/personal/tubesync/rfcs/rfc-tubesync-core-architecture.md#adr-05-fatiamento-de-testes-vitest--happy-dom-como-base-e-playwright-e2e)):**
   - **Decisão:** **Vitest + Happy-DOM** como motor de testes unitários e de integração prioritário com harness de mocks para `webextension-polyfill` (`browser.*`), com threshold bloqueante de $\ge 80\%$ de cobertura de linhas/branches no GitHub Actions.
   - **Playwright E2E:** Alocado para a etapa final de homologação da release candidate (desempacotamento e injeção real em Chromium).
3. **Resiliência e Governança de Rate Limit ([`ADR-02`](file:///home/ozymandias/code-documentation/personal/tubesync/rfcs/rfc-tubesync-core-architecture.md#adr-02-fila-leaky-bucket-3-reqs-com-exponential-backoff-e-full-jitter)):**
   - Fila centralizada **Leaky Bucket** garantindo despacho $\le 3\text{ req/s}$ para a API do Notion, somada a recuo exponencial com **Full Jitter** e Circuit Breaker de 3 estados (`CLOSED`, `OPEN`, `HALF_OPEN`).
4. **Eficiência no DOM do YouTube ([`ADR-03`](file:///home/ozymandias/code-documentation/personal/tubesync/rfcs/rfc-tubesync-core-architecture.md#adr-03-substituição-de-mutationobserver-contínuo-por-eventos-nativos-do-polymer)):**
   - Eliminação do `MutationObserver` contínuo em `document.documentElement` em favor dos eventos canônicos do Polymer (`yt-navigate-finish` e `yt-page-data-updated`).
5. **Paridade Multi-Browser ([`ADR-04`](file:///home/ozymandias/code-documentation/personal/tubesync/rfcs/rfc-tubesync-core-architecture.md#adr-04-migração-integral-para-webextension-polyfill-browser)):**
   - Remoção de todas as chamadas proprietárias legadas `chrome.*` com callbacks em benefício estrito de `browser.*` via [`webextension-polyfill`](file:///home/ozymandias/Code/tubesync/package.json#L16).
